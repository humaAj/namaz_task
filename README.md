# Jamaat Times Android Application

A Java-based Android application developed during my MSc to provide users with prayer and Jamaat timings based on their location.

## Project Overview

**Jamaat Times** is a location-aware Android application designed to help users find prayer timings and information about nearby mosques.

The application uses the user's location to update the displayed information. When a user moves to another city, the application can detect the change in location and provide relevant prayer timings and nearby mosque information.

## Features

* 🕌 View prayer and Jamaat timings
* 📍 Location-based information
* 🔄 Update information when the user changes location
* 🕌 Display nearby mosques
* 📱 Android-based mobile application

## Technologies

* Java
* Android
* Location/GPS services

## Project Purpose

The purpose of this project was to develop a practical Android application that combines mobile application development with location-based services to provide users with useful prayer and mosque information.

## Project Background

This application was developed as part of my MSc academic work and provided practical experience in Android application development, Java programming, and location-based services.
